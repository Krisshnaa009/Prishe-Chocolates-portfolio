# PRISHE — Premium Homemade Chocolates

Welcome to the **PRISHE** portfolio website! PRISHE is a brand of premium homemade chocolates handcrafted with care and a personal touch in India, owned by Priyanka Gupta.

## About the Project
This repository contains the front-end code for the PRISHE portfolio and product catalog. The website is built with plain HTML, CSS, and vanilla JavaScript to ensure a fast, lightweight, and modern browsing experience.

## Features
- **Modern & Elegant Design**: A beautiful, premium aesthetic fitting for artisanal chocolates.
- **Product Showcase**: Displays the signature "Dark Edit" collection (55% dark couverture) and mini bites.
- **Responsive Layout**: Designed to look great on desktop and mobile devices.
- **Micro-animations**: Smooth reveal animations as you scroll down the page.
- **Easy Contact**: Direct links to inquire and order via WhatsApp and Instagram.

## Technologies Used
- HTML5
- CSS3 (Custom styles with a dark, rich theme)
- Vanilla JavaScript (for interactivity like mobile menu, scroll reveals, and product dialogs)

## Getting Started
To view this project locally:
1. Clone the repository.
2. Open `index.html` in any modern web browser.
